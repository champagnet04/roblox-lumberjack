# Scout Patches

A reward system for solo play, raised by the owner on 2026-10-12: boy scout or girl scout style patches earned for doing missions. **Nothing here is built.** The rules below were decided by quiz on 2026-10-13. The list of patches is Claude's draft; the owner looked it over the same day and said the plan "looks good for now", to be added later. Names and numbers can still change when it is built.

## Decisions (owner)

| Subject | Decision |
|---|---|
| Where | Single player mode |
| How earned | By doing a mission. Each mission has one patch, earned once. No bronze, silver and gold levels |
| Camp stages | Every stage finished earns a patch: seven in all |
| Clearing trees | Several patches of this kind, and one of them is felling the whole forest in one game |
| Kinds of mission | All four: skill in one game, close calls with the guardian, long-term totals, and coming back on different days |
| Reward | Just the patch. No wood and no boost |
| Where patches are seen | A page on the menu, a button during the game, and worn on the character |
| Look | A round stitched cloth badge with a simple picture in the middle, like a real merit badge. Drawn by a script, as the icon and thumbnail were |
| Players already part-way | They are given the patch for every stage already finished, straight away |
| Roblox badges | Only the big ones: the seven stage patches and a few of the hardest. The rest live in the game only |

About Roblox badges: the owner pays to create them, players never pay. A game can create about 5 free each day and Roblox charges for more (100 Robux each when last known; check the Creator Dashboard). Awarding them is free. Each is made by hand on the Roblox site.

## Things to know

- **The whole forest is 420 trees, and 990 once it has grown for the cabin stage.** Felled trees stay down for the whole game in solo, so it can be done, but the guardian wakes after every few trees. It will be a patch very few players own, which seems to be the point.
- **Totals start counting when patches are built.** The game has not been keeping count of trees felled, materials found or days played. Stages finished are known already, which is why those patches can be given straight away.
- **Wearing patches on the character is the largest piece.** A sash has to be built onto the lumberjack and each patch shown on it, where they are very small. It could come after the menu page and the in-game button.
